# MyMidiKeyboard
This is MiDi keyboard based on Kai pereira's starter project (https://github.com/KaiPereira/MIDI-Keypad/ project).

<img width="1599" height="857" alt="Screenshot_66" src="https://github.com/user-attachments/assets/af6aa8aa-b273-475e-8588-57dca221f2c4" />
It is based on Waveshare ESP32-S3-Zero microcontroller, has capacitive touch panels, EC11 rotary encoder, Kailh Choc Low-Profile Switches, Bourns Slide Potentiometers and a SK6812 MINI-E Neopixels. it is meqant to be used with pc in apps such as FL studio.
As a firmware you can use KMK (https://github.com/KMKfw/kmk_firmware/blob/main/docs/en/Getting_Started.md)
